# Expense Splitter

> **A multi-page group expense tracker that settles debts with the fewest possible payments.**

Add members, log shared bills, and instantly see who owes what — the app uses an exact minimum-transaction algorithm so your group always clears up in as few transfers as possible. All data is saved locally in your browser; no account or backend needed.

**Live site:** _[https://expense-splitter-tracker.vercel.app/]_
**Github link:** _[https://github.com/Karan9110/expense-splitter-tracker]_
